PULSEBOUND
==========
A self-contained neon arena roguelite made with vanilla HTML/CSS/JavaScript.

Run locally
------------
1. Unzip the folder.
2. Open index.html in a modern browser.

Desktop controls
----------------
WASD / Arrow Keys  Move
Mouse              Aim
Left Mouse         Fire
Space              Dash
Esc                Pause

Mobile
------
Left circle: move
Right circle: aim + fire
Dash button: dash

Notes
-----
- No external libraries, servers, or asset downloads are required.
- Audio is synthesized in-browser with Web Audio.
- High score, best wave, and run count are stored in localStorage.
- The game uses short-session progression, skill-based mastery, build variety,
  and readable risk/reward rather than ads, loot boxes, artificial scarcity,
  or forced retention mechanics.
